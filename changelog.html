Release history

Every released version of Spamify, newest first. Current version: 1.2.0 · requires WordPress 5.8+, PHP 7.4+ · tested up to 7.1.

1.2.0LatestOctober 16, 2026

New features

  • Added German (de_DE), Spanish (es_ES) and French (fr_FR) translations covering the admin screens and the visitor-facing form messages.
  • Per-zone rate-limit overrides — give a zone (e.g. comments) its own independent submission budget instead of sharing the global limit.
  • Honeypot and "submitted too fast" detections can now flag for review instead of always hard-blocking.
  • Greylist-aware SMTP checks — a temporary response gets one automatic re-check a few minutes later instead of caching the inconclusive result for an hour.
  • Hide Login Attempts stat card on the Dashboard shows today's and this week's denied probes of the real login address.
  • Spam Scan "Review candidates" filter surfaces clean-looking accounts that have prior flagged or blocked activity on file.
  • Send test digest now button previews the digest email immediately.
  • Run GDPR purge now button applies the retention window immediately.
  • Review Queue "Dismiss all" clears every currently-filtered flagged submission in one action.
  • The setup wizard pre-checks a form-plugin zone only when that plugin is actually active.

Fixes

  • The honeypot's "submitted too quickly" message now reaches blocked visitors.
  • A domain with no mail server at all (no MX or A record) is now blocked, not just flagged.
  • Removed the redundant "full" Real-Time Check Mode, which was identical to "fast".
  • First-activation settings now always match "Reset to Defaults" (IP anonymisation and log retention defaults no longer disagree).

Internal

  • Dashboard stat cards extracted into their own class; the Spam Scan table gained an indexed column (DB schema v15) that upgrades automatically.

1.1.0September 14, 2026

New features

  • The Activity banner now appears on every tab (Log, Review Queue, Timeline and Pro sections).
  • A loading indicator for every AJAX action and page navigation across the admin screens.

Security

  • Re-audited every AJAX endpoint to confirm nonce verification and capability checks are in place.

Fixes

  • Flag and Block thresholds now behave distinctly: Flag Threshold means "allow, but mark for review"; only Block Threshold rejects — so the Review Queue receives real submissions.
  • The admin banner is now light instead of dark, matching the rest of the admin UI.

Internal

  • Every source file is under 400 lines; admin pages, engine layers and stylesheets split into focused parts.
  • JavaScript migrated to wp.i18n so every browser string is translatable.

1.0.1September 8, 2026

New features

  • Continuous Spam Scan — retro-scans survive a page reload, and Pause/Resume picks up exactly where it left off.
  • Behavior & Bot Signals layer — headless-browser detection, keystroke rhythm, mouse/keyboard/focus activity and a JS challenge, all collected locally.
  • Review Queue — every flagged submission across comments, registrations, profiles and connected forms in one screen.
  • Timeline — a visual "why was this blocked" history per IP or email across all zones.
  • WP Dashboard widget with today's and this week's blocked/flagged counts.
  • Digest emails daily, weekly or monthly, optionally with a CSV summary attached.

Fixes

  • The Activity Log "Delete entry" button now actually deletes the row.
  • The Spam Scan "no offline Tor/ASN dataset" notice renders as a normal banner.

1.0.0Initial releaseSeptember 1, 2026

Features

  • Hide login — serve wp-login.php (and /wp-admin/ for logged-out visitors) from a custom address, with a 404, home redirect or URL of your choice; all login links are rewritten.
  • Multisite — per-site login addresses, subdirectory-network aware, and an optional SPAMIFY_HIDE_LOGIN_SLUG constant to enforce one address network-wide.
  • Syntax validation, optional SMTP mailbox verification, honeypot & timing, per-IP rate limiting, allowlist, invisible CAPTCHA (bring your own keys), GDPR log tools, Site Health checks and a setup wizard.
  • Integrations for WordPress core forms, Contact Form 7, WPForms, Jetpack Forms and Elementor Forms.
